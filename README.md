# ict1209-fitness-tracker
Mini Project for ICT 1209: Web Technologies (23/24 Batch). Interactive Fitness Tracker web application developed by Index Numbers: 2772 &amp; 2773.

A Note on Development Methodology & Git Commits:
The complex backend architecture (PHP session routing and MySQL integration) was developed using the Agile Pair Programming methodology. To ensure seamless database integration and avoid local XAMPP environment conflicts, the backend team members authored the core logic collaboratively on a single local workstation.

Consequently, the Git commit history for Phase 3 reflects pushes from a single unified repository account. This was a deliberate version control strategy to maintain a clean, conflict-free main branch while multiple members actively engineered the code side-by-side.
